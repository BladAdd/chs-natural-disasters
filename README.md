# ЧС природного характера — презентация для урока ОБЗР

Интерактивная веб-презентация по теме **«Чрезвычайные ситуации природного характера»** для школьного урока ОБЗР (9–11 класс).

## 🔗 Ссылки

- **Vercel:** https://chs-natural-disasters.vercel.app
- **GitHub Pages:** https://bladadd.github.io/chs-natural-disasters/
- **Репозиторий:** https://github.com/BladAdd/chs-natural-disasters

## Что внутри

- **25 слайдов** с полноценной анимацией
- **🌐 Настоящая 3D-Земля** (WebGL): шар с реальной текстурой NASA, города ночью, атмосфера и звёзды
  - **Живые данные USGS** — прямое подключение к официальному каталогу землетрясений
  - **33 000+ землетрясений с 1950 года** в офлайн-каталоге (работает без интернета)
  - **Прокрутка времени**: поставь любую дату и смотри, как накапливались события
  - **Плей и скорость** — события появляются во времени, с «следом» последних толчков
  - **Регионы**: весь мир / Россия / Оренбургская область
  - **Легендарные катастрофы**: цунами, вулканы, циклоны, метеориты, лавины — с точными датами
- **33 реальные фотографии** из Wikimedia Commons вместо нарисованных иллюстраций
- Разбор **всех основных видов природных ЧС** с причинами, механизмом, опасностями и признаками
- Отдельные блоки **«Россия»** и **«Оренбургская область»** с региональными рисками и памяткой
- **Памятки по защите** + таблица «куда и как спасаться» для каждого бедствия
- **Интерактивный мини-тест** из 9 вопросов с разбором ответов
- Адаптивная вёрстка, режим показа с клавиатуры, режим обзора слайдов, полноэкранный режим

## Как пользоваться 3D-картой

| Действие | Как |
|---|---|
| Вращать Землю | тянуть мышью / пальцем |
| Приблизить | колесо мыши |
| Посмотреть событие | клик по точке на карте |
| Поставить дату | поле даты + кнопка «Показать эту дату» |
| Прокрутить историю | ползунок времени или кнопка «Играть» |
| Сменить регион | выпадающий список или кнопки справа |
| Открыть катастрофу | клик по строке в списке «Легендарные катастрофы» |

## Управление

| Клавиша | Действие |
|---|---|
| `→` `Space` `Enter` | следующий слайд |
| `←` `Backspace` | предыдущий слайд |
| `Home` / `End` | первый / последний слайд |
| `O` | обзор всех слайдов |
| `F` | полноэкранный режим |
| `Esc` | закрыть обзор |
| колесо мыши / свайп | листать слайды |

## Запуск локально

```bash
npm run dev     # http://localhost:5173
```

или просто откройте `index.html` в браузере.

## Сборка и деплой

```bash
npm run build   # собирает статику в dist/
npm run deploy  # публикует на Vercel
```

Проект — статический сайт (HTML + CSS + JS), без зависимостей и без сборки.
Внешних картинок нет: вся графика — авторский SVG, поэтому сайт быстрый и работает офлайн.

## Структура

```
index.html                    — разметка слайдов и фотографии
assets/css/style.css          — дизайн-система, слайды, анимации, панель 3D-карты
assets/js/app.js              — навигация, обзор, полный экран, лайтбокс, мини-тест
assets/js/globe.js            — 3D-Земля (three.js): маркеры, таймлайн, режимы
assets/vendor/three.*.js      — three.js (WebGL-движок)
assets/img/                   — фотографии, текстуры Земли
assets/data/quakes-*.csv      — каталоги землетрясений USGS (мир, Россия, Оренбуржье)
assets/data/hazards.json      — легендарные катастрофы с датами и координатами
scripts/serve.js              — локальный сервер без зависимостей
scripts/build.js              — сборка статики в dist/
```
