# ЧС природного характера — презентация для урока ОБЗР

Интерактивная веб-презентация по теме **«Чрезвычайные ситуации природного характера»** для школьного урока ОБЗР (9–11 класс).

## 🔗 Ссылки

- **Vercel:** https://chs-natural-disasters.vercel.app
- **GitHub Pages:** https://bladadd.github.io/chs-natural-disasters/
- **Репозиторий:** https://github.com/BladAdd/chs-natural-disasters

## Что внутри

- **19 слайдов** с полноценной анимацией
- **9 векторных SVG-сцен**, анимированных через CSS: землетрясение, цунами, торнадо, ураган, извержение вулкана, наводнение, оползень, лесной пожар, гроза с градом
- Разбор **всех основных видов природных ЧС** с причинами, механизмом, опасностями и признаками
- **Памятки по защите** + таблица «куда и как спасаться» для каждого бедствия
- **Интерактивный мини-тест** из 6 вопросов с разбором ответов
- Адаптивная вёрстка, режим показа с клавиатуры, режим обзора слайдов, полноэкранный режим

## Управление

| Клавиша | Действие |
|---|---|
| `→` `Space` `Enter` | следующий слайд |
| `←` `Backspace` | предыдущий слайд |
| `Home` / `End` | первый / последний слайд |
| `O` | обзор всех слайдов |
| `F` | полноэкранный режим |
| `Esc` | закрыть обзор |
| колесо мыши / свайп | листать слайды |

## Запуск локально

```bash
npm run dev     # http://localhost:5173
```

или просто откройте `index.html` в браузере.

## Сборка и деплой

```bash
npm run build   # собирает статику в dist/
npm run deploy  # публикует на Vercel
```

Проект — статический сайт (HTML + CSS + JS), без зависимостей и без сборки.
Внешних картинок нет: вся графика — авторский SVG, поэтому сайт быстрый и работает офлайн.

## Структура

```
index.html            — разметка слайдов и SVG-сцены
assets/css/style.css  — дизайн-система, слайды, анимации
assets/js/app.js      — навигация, обзор, полный экран, мини-тест
```
