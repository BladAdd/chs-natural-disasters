### Ключевые факты, на которые опирается презентация

- **Оренбургская область:** 123 702 км², 1,82 млн жителей, амплитуда температур 34–38 °C,
  осадки 350–450 мм в год (60–70% — летом), река Урал (1164 км в области),
  озеро Шалкар-Ега-Кара (9600 га), чернозёмы на 79% пашни.
- **Сейсмика области:** по каталогу USGS за 1950–2026 год — всего **20 землетрясений M ≥ 2**,
  максимум **М5,4** в 1984 году в 21 км от Илека. Область сейсмически спокойна.
- **Камчатское цунами 1952 года:** М9,0, 223 погибших, высота волны на Курилах до 8–10 м.
- **Камчатка, июль 2024:** М8,8, цунами до 10 метров.
- **Челябинский метеорит, 15.02.2013:** осколочное облако пробило тропосферу, стёкла разбились в 100 км.

## Как пользоваться 3D-картой

| Действие | Как |
|---|---|
| Вращать Землю | тянуть мышью / пальцем |
| Приблизить | колесо мыши |
| Посмотреть событие | навести курсор (подсказка) или кликнуть по точке |
| Подлететь к событию | кнопка «Показать окрестности» в карточке события |
| Поставить дату | поле даты + кнопка «Показать дату» |
| Прокрутить историю | ползунок времени или кнопка «Играть» |
| Сменить регион | Мир / Россия / Оренбуржье |
| Открыть катастрофу | клик по строке в списке «Катастрофы» |
| Играть / пауза | `Пробел` |
| Шаг по времени | `,` и `.` |
| Размер окна | `[` и `]` |
| Обзор планеты | кнопка «Обзор планеты» |

### Что умеет карта

- **Два режима времени.** «Хроника» показывает события вокруг выбранной даты — видно, как разворачивалось бедствие. «Накопление» — всё, что произошло до этой даты.
- **Семь размеров окна**: от одних суток до всей истории.
- **Настоящее Солнце.** Терминатор (граница дня и ночи) вычисляется для выбранной даты: видно, где тогда было светло, а где темно.
- **Афтершоки.** У самого сильного события в окне рисуются дуги к его афтершокам — до 45 суток и 700 км.
- **Слои**: землетрясения, катастрофы, афтершоки, координатная сетка, подписи.
- **Автоподлёт**: поставил дату крупного события — камера сама подлетает к эпицентру и показывает волну.
- **Запасной 2D-режим**: если на школьном компьютере нет WebGL, карта рисуется плоской — с теми же данными, датами и управлением.

## Запуск локально

```bash
npm run dev     # http://localhost:5173
```

или просто откройте `index.html` в браузере.

## Сборка и деплой

```bash
npm run build   # собирает статику в dist/
npm run deploy  # публикует на Vercel
```

Проект — статический сайт (HTML + CSS + JS), без зависимостей и без сборки.
Внешних картинок нет: вся графика — авторский SVG, поэтому сайт быстрый и работает офлайн.

## Структура

```
index.html                    — разметка слайдов и фотографии
assets/css/style.css          — дизайн-система, слайды, анимации, панель 3D-карты
assets/js/app.js              — навигация, обзор, полный экран, лайтбокс, мини-тест
assets/js/globe.js            — 3D-Земля (three.js): маркеры, таймлайн, режимы
assets/vendor/three.*.js      — three.js (WebGL-движок)
assets/img/                   — фотографии, текстуры Земли
assets/data/quakes-*.csv      — каталоги землетрясений USGS (мир, Россия, Оренбуржье)
assets/data/hazards.json      — легендарные катастрофы с датами и координатами
scripts/serve.js              — локальный сервер без зависимостей
scripts/build.js              — сборка статики в dist/
```
